# TASK-4-NWANNE-EMMANUELLA-CHIJINDU
Repository for UIUX Design Project 4 on Prototyping

Project Description

This project was completed as part of the Code Labs Internship program. The focus of this task was to transform static UI designs into an interactive prototype that demonstrates how the application works in real time.

The goal was to help stakeholders experience the flow, transitions, and interactions of the app before it is handed off to developers.

Scenario

Although the UI design was completed, stakeholders needed to feel how the application functions. They wanted to see button clicks, screen transitions, and the overall user flow to better understand the product experience.

Project Objective

The objective of this project was to:

Bring static designs to life using interactions
Connect all screens using prototyping links
Demonstrate user flow clearly from screen to screen
Add micro-interactions such as button clicks and smooth transitions
Design Approach

To achieve this, I:

Connected all screens using Figma Prototype mode
Defined clear navigation paths between screens
Added interactive elements such as button clicks
Applied smooth transitions to simulate real app behavior

This approach helps communicate functionality clearly to stakeholders and developers.

Outcome

The final result is a clickable prototype that behaves like a real application. It allows stakeholders to interact with the design, understand the user journey, and validate the overall flow before development begins.
